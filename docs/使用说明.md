🎯 什么是Map-LLM？
Map-LLM是一个智能地图制作助手，您只需要用中文描述您想要的地图，系统就能自动生成专业的地理信息图。
核心优势：
- 🗣️ 说话就能做图：用中文描述需求，无需学习复杂软件
- 🎯 自动优化：系统自动计算最佳地图范围和样式
- 🎨 专业美观：输出符合制图标准的高质量地图
- ⚡ 快速高效：几分钟完成传统软件需要几小时的工作
🎨 如何描述您想要的地图
基本地图设置
您可以在描述中包含以下内容：
🖼️ 地图外观
- 标题：`"标题：广东省行政区划图"`
- 背景色：`"背景色：浅蓝色"` 或 `"背景色：白色"`
- 图片大小：`"图片大小：(12, 8)"` - 数字越大图片越大
- 清晰度：`"分辨率：300"` - 用于打印，`"分辨率：150"` - 用于屏幕显示
🗺️ 地图元素控制
- 图例：`"显示图例"` 或 `"不显示图例"`
- 比例尺：`"显示比例尺"` 或 `"不显示比例尺"`
- 指北针：`"显示指北针"` 或 `"不显示指北针"`

示例描述：
"创建广东省地图，标题为'广东省行政区划'，背景色用浅蓝色，
图片大小(10, 8)，分辨率300，显示图例和比例尺，不显示指北针"
🎯 图层和样式设置
📁 指定数据文件
告诉系统使用哪些地理数据文件：
- "使用Guangdong.shp" - 广东省行政区划
- "使用Highway.shp" - 高速公路网络
- "使用Railway.shp" - 铁路网络
- "使用所有shp文件" - 使用该目录下所有数据
🎨 设置图层样式
颜色设置：
- "红色", "蓝色", "绿色", "橙色", "紫色"
- "浅蓝色", "深红色", "浅绿色"
- "#FF0000" (十六进制颜色代码)
线条样式：
- "实线" - 普通连续线条
- "虚线" - 断续线条  
- "点线" - 点状线条
- "线宽2", "线宽1.5" - 控制线条粗细
透明度：
- "透明度0.8" - 80%不透明
- "半透明" - 50%透明度
标签设置：
- "添加地名标签" - 显示地名
- "字体大小12" - 设置文字大小
- "根据'地区'属性分类着色" - 按属性自动配色
示例描述：
"Highway.shp用红色实线，线宽2.5，透明度0.8
Railway.shp用蓝色虚线，线宽2
Guangdong.shp根据'地区'属性分类着色，添加'地名'标签"
📝 添加文字说明
💬 地图注记
在地图上添加说明文字：
"添加说明：广东省是中国经济最发达的省份之一"
"添加注记：珠三角地区是全国重要的经济中心"
🏷️ 图例设置
- "图例标题：行政区划类型"
- "图例字体大小：10"
💾 保存设置
📁 文件输出
- "格式：PNG" - 图片格式（PNG/JPG/PDF/SVG）
- "分辨率：300" - 输出质量
文件格式选择：
- PNG - 网页使用、文档插图（推荐）
- JPG - 照片、大图文件
- PDF - 印刷、报告
- SVG - 矢量图、可编辑
分辨率建议：
- 150 - 屏幕显示
- 300 - 文档打印（推荐）
- 600 - 高质量印刷
示例描述：
"保存格式为PNG，分辨率300"

🛤️ 路网综合任务使用说明
什么是路网综合？
路网综合是地图制图中的重要环节，当地图比例尺从大变小（如从1:500缩编到1:20000）时，需要对路网进行自动化选取和简化，保留主要道路结构，删除次要道路，使地图在小比例尺下仍然清晰易读。
核心功能：
- 🎯 自动缩编：根据目标比例尺自动选取保留的道路
- 🧠 智能选取：支持多种算法，适应不同数据特点
- 📊 对比可视化：生成综合前后的对比图，直观展示效果
- ⚡ 高效处理：快速完成大规模路网数据的综合处理
🔧 可用的综合算法
